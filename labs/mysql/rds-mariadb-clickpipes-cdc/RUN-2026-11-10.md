## Rows

Target read with `FINAL`: 2,500 rows, 10 with `_peerdb_is_deleted = 1`, so 2,490 live — equal (01:32 UTC). The 72h and 168h pipes created at 01:16–01:17 also hold 2,490.

## Terraform

`terraform/main.tf` (`rdsmariadb`, retention 24, before the `rds_configuration` grant): provider 3.42.0 and 3.41.0 both created the pipe, which reached `Running`, but `apply` ended with `Provider returned invalid result object after apply … source.mysql.server_id` and left the resource tainted (the next plan wanted to replace it). `terraform untaint clickhouse_clickpipe.mariadb_cdc` made the next plan `No changes`. Setting `server_id` explicitly failed at create (`failed to query source for registered replicas`) — that lookup needs a privilege the RDS master user cannot grant (`REPLICATION MASTER ADMIN`).
