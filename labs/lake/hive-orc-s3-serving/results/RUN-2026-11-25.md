## What did not work

- **Hive and HDFS engines.** `CREATE TABLE … ENGINE = Hive(...)` →
  `Not enough privileges. To execute this query, it's necessary to have the grant TABLE ENGINE ON Hive.`;
  `hdfs()` → `… grant READ ON HDFS`. Same for the `default` user and the SQL console user, and
  `GRANT TABLE ENGINE ON Hive TO default` → `… necessary to have the grant TABLE ENGINE ON Hive WITH GRANT OPTION`.
  The `S3` engine is allowed for the same user.
- **Glue catalog over Hive tables.** `DataLakeCatalog` (`catalog_type = 'glue'`, `aws_role_arn`):
  `SHOW TABLES` lists only the Iceberg table; `SELECT` on `game_lake.events_raw` →
  `Cannot read table … because it has no table_type … readable tables must have equalsIgnoreCase(table_type, 'ICEBERG')`.
- **Glue catalog over Iceberg, same run.** The Athena CTAS Iceberg table is listed, but 4 of 4
  SELECTs failed: `AuthorizationHeaderMalformed … the region 'us-east-1' is wrong; expecting 'ap-northeast-2'`
  (or `Cannot read Iceberg avro manifest file …` with the same cause). `storage_endpoint` set to the
  regional endpoint gave `Access Denied … bucket 'default'`; set to the bucket's virtual-host endpoint, 404.
  Not investigated further here.
- **Nullable payload.** ORC columns are inferred as `Nullable(...)`; `JSONExtract(payload, …, 'Array(Tuple(…))')`
  failed with `Nested type Array(…) cannot be inside Nullable type` until `ifNull(payload, '')`.
- **Spark History Server** from the EMR console opens a pop-up that the browser blocked
  (`User interface for Spark History Server … failed to load`), so there is no Spark UI capture.
- **Leftovers.** The first Hive client on EMR created a Glue `default` database (HDFS location);
  `99-destroy.sh` now drops it when it is empty and points at HDFS. EMR-managed security groups
  `ElasticMapReduce-master` / `-slave` stay in the default VPC (no charge).
